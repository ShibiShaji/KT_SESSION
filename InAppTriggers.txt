1. NEW EVENT REQUEST CREATED
   - When Triggered: A user or event requestor submits a new event request form.
   - Code File: apps/event-api/src/services/event-request.service.ts (line 183)
   - Receiver: All Facility Managers (roleId = 1)
   - Notification Type: NotificationType.CREATED
   - Title: 📋 New Event Request
   - Message: "{requestorName} requested: '{eventName}'"
   - Next Action / Deep Link: Opens event request details (/events/:id)

2. EVENT REQUEST APPROVED

   - Code File: apps/event-api/src/services/event-request.service.ts (line 1379)
